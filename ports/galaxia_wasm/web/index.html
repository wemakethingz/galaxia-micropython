Galaxia — WebAssembly

chargement…

La carte tourne dans votre navigateur : MicroPython et le code Thingz du firmware, compilés en WebAssembly. Touches A et B du clavier quand ni le terminal ni l'éditeur n'ont le focus. La radio relie les cartes ouvertes dans d'autres onglets de ce navigateur.

Capteurs

Accéléromètre

Boussole, température, lumière

Température : celle de la puce, le firmware en retire son décalage de calibration (set_temperature_offset), comme sur la carte.

Wi-Fi de la classe

Un point d'accès simulé, sans Internet, partagé par les cartes ouvertes dans ce navigateur. Les cartes peuvent aussi créer leur propre point d'accès (network.WLAN(network.AP_IF)).

Broker MQTT

Le seul hôte de l'Internet simulé, derrière le Wi-Fi de la classe : ces noms mènent à lui (port 1883, sans TLS). MQTT 3.1.1, sessions propres, messages retenus, dernière volonté. Un des onglets ouverts l'héberge.

Programme

Les fichiers de la carte (main.py, journal…) sont gardés dans ce navigateur.
